# Versions

这个目录记录已经接近发布门槛的版本快照。它不是需求池，也不是 bug 清单，而是面向发布和回顾的归档层。

## 这里放什么

- 版本说明
- 发布检查项
- 已完成的全链路测试结果
- 发布风险与回滚说明

## 推荐结构

- `version.md`：一个版本的说明、包含范围、验证和发布结论

## 状态词

版本对应的系统门槛是：

`idle` -> `integrating` -> `full_flow_test_passed` -> `releasable`

版本文档通常只接收已经到达 `releasable` 的内容，或者即将发布的候选快照。

## 当前仓库状态

- 后端 scaffold 已存在，但前端和测试仍在补骨架
- 所以现在更适合维护“候选版本记录”，而不是正式发布记录
- 等主链路能跑通，再把这里作为发布归档入口

## 写作原则

- 记录版本里真正包含了什么
- 记录哪些测试已经通过
- 记录是否可以回滚
- 记录发布后要继续做什么
